## 预先登记的解释边界

- 采用固定8192 bins、`0.5+atan(score)/pi`单调映射的近似AP；这是分布式直方图选参变体。每个候选与精确集中式AP的误差、选择一致性及最终分数差均保留。不能预先宣称与原Full完全等价。校准矩数值等价容差为1e-10。
- 10个客户端在同一服务器模拟，通过显式数值消息序列化统计负载；不宣称多机网络测速、密码学安全聚合或正式隐私保证。稀疏直方图仍可能泄露信息。
- FedMVP基线明确称“FedMPT发布仓库的多标签适配版”，不是原ICCV单标签、LLM属性版本的严格复现。模型关键源码不一致时禁止自动进入长训练。
- FedMPT论文与现有发布实现的条件、视觉适配器、OT和概率/损失定义有差异；未把更改OT开关当成作者等价复现。原修补版数值保留。
- 200轮为固定预算，不根据测试mAP延长或选择最佳轮。新增基线仅最终轮评估测试集。
- 原Full的7/17/27是三个训练划分组件；配对bootstrap仅反映给定模型的测试样本不确定性。新增基线的7/17/27是固定partition7下的独立训练种子，不混为同一种随机性。
- 冷缓存指没有预计算特征；不会强制清除系统页缓存。实际时间包括数据读取；原修补FedMPT跨设备累计耗时不纳入同硬件基准。
